Available Read-Only MCP Tools

        

          

            

              
1. list_tabs

              
Lists all available tabs and worksheets in the target Google Sheet.

              
Params: none

            


            

              
2. get_schema

              
Returns column headers, auto-detected types (number, boolean, date, text), total row count, and top 3 sample rows.

              
Params: { include_samples: boolean }

            


            

              
3. query_rows

              
Executes high-performance filtering, full-text search, sorting, limit/offset pagination, column projection, and aggregations (count, sum, avg, min, max, group_by).

              
Params: { search, filters, sort, order, limit, offset, fields, aggregate, group_by }
